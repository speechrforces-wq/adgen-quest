Подключение Supabase

Для начала вставь publishable / anon key проекта Supabase. Он предназначен для клиентских приложений. Не вводи service_role или secret key.

Ключ сохраняется только в этом браузере. Supabase должен разрешать вход по email и паролю.

📥 Импорт без скачивания из ChatGPT

Шаг 1: Сохрани архив, скачанный непосредственно с LinkedIn, в «Файлы» iPhone. Шаг 2: нажми поле ниже и выбери архив. Шаг 3: нажми «Импортировать контакты». Файл из чата ChatGPT здесь не нужен.

После импорта список появится во вкладке 👥 Контакты.
