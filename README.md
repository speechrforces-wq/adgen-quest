# AdGen Quest

Private team workspace for Aleksandr and Andrey: prospecting, outreach preparation, company research, quests, tasks and content planning.

## Security
This repository contains **no private LinkedIn exports, personal contacts, chat transcripts, credentials, or customer records**.
Never commit CSV/ZIP LinkedIn exports or Supabase service-role keys.
Sensitive data belongs in a separately configured backend with authentication and row-level access policies.
